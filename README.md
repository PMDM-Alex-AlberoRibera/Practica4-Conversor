# Practica4-Conversor
> Aplicación móvil desarrollada para el módulo de **Programación Multimedia y Dispositivos Móviles (PMDM)**.

---

## 📋 Descripción del Proyecto
**Practica4-Conversor** es una aplicación diseñada para dispositivos móviles que permite realizar de forma rápida e intuitiva diferentes tipos de conversiones (por ejemplo: unidades de medida, divisas, temperatura, etc.). Su objetivo principal es ofrecer una interfaz limpia, responsiva y fácil de usar, aplicando buenas prácticas de desarrollo móvil.

---

## ✨ Características Principales
- 🔄 **Conversiones dinámicas:** Cálculo en tiempo real a medida que el usuario introduce los datos.
- 🎨 **Interfaz de usuario intuitiva:** Diseño adaptado a las pautas de UI/UX móvil para una experiencia de usuario fluida.
- 🛡️ **Validación de entradas:** Control de errores ante campos vacíos, caracteres no numéricos o valores no válidos.
- 📱 **Soportable y adaptable:** Compatible con diferentes tamaños de pantalla y orientaciones.
